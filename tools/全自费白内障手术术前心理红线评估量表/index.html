使用说明

  1. ①  初评：由宣教护士于术前宣教环节完成，逐项询问并勾选评估结果；
  2. ②  复核：主诊医生在最终方案确认前独立审阅，对每项「预警」深入追问，对任何「拦截」项须专项记录；
  3. ③  复核：任何一项触发「拦截」，先暂停最终方案确认，由主诊医生核实原因、记录处理意见；量表结果不能单独决定手术适应证；
  4. ④  归档：签署完成后附入病历档案，作为知情同意过程的组成部分。

第一域   期望值与术后视觉目标
编号评估项目询问 / 观察要点判定标准评估结果
C-01 对手术目标的根本误判 询问：「您做这次手术最希望改善的是什么？」
观察：误以为手术可恢复至20岁时视力，或认为白内障手术可完全"治愈老花"；主诉「我就是要看得比年轻时更好」者。
期望明显超出白内障手术光学改善范围，判定【预警/拦截】
C-02 对光晕 / 眩光零容忍 询问：「夜间开车时若出现轻微光圈或星芒，您能接受吗？」
观察：拒绝任何光学副作用，强调「跟年轻时一样」；选择Synergy/PureSee但坚持无任何夜视干扰者。
对光学副作用完全零容忍，判定【拦截】
C-03 绝对脱镜执念 询问：「术后阅读时若偶尔需配薄镜片，您能接受吗？」
观察：明确拒绝任何场景戴镜，表示「我花这个钱就是为了再也不戴眼镜」者。
明确拒绝任何场景配镜，判定【拦截】
C-04 对FLACS效果过度期望 仅限选择FLACS患者
询问：「您了解飞秒激光辅助手术的作用吗？」
观察：认为FLACS可确保「零误差绝对安全」；或误以为价格更高意味着视觉质量一定更好者。
对FLACS技术存在根本误解或过度神化，判定【预警/拦截】
C-05 特殊职业视力要求未核实 询问：职业及是否有硬性视力体检要求（职业驾驶员、飞行员、军警等）。
观察：误以为植入高端IOL可绕开视力体检标准，或不了解术后视力认定规则者。
职业有硬性视力法规要求且未核实，判定【拦截】
第二域   全自费升级决策质量
编号评估项目询问 / 观察要点判定标准评估结果
C-06 未理解「全自费升级」含义 询问：「您知道本院有哪些合理方案？每种方案中哪些费用可能由医保支付，哪些需要自己支付？」
观察：对方案、费用组成或本地医保政策有误解；以本院正式费用说明为准。
仍不清楚方案与费用边界：暂停费用选择确认，重新解释并请医生复核。
C-07 对所选高端IOL存在根本性误解 测试：请患者用自己的话描述所选IOL的主要特点和局限性。
例：选PureSee但认为「可以看远中近三距离完全无光晕」；选Synergy但认为「和单焦点一样稳定」；选Odyssey但不知道属于全视程IOL者。
对所选IOL存在重大临床误解，判定【预警/拦截】
C-08 对FLACS（LOI耗材）费用认知偏差 仅限选择FLACS患者
询问：「您知道每次手术需使用一个LOI耗材，费用全部自费，是吗？」
观察：不知晓LOI为一次性耗材，或确认价格后表现异常犹豫、沉默者。
不知晓LOI为全自费一次性消耗，判定【预警】
C-09 无法复述本次手术核心风险 测试：请患者用自己的话说出「这次手术最主要的两个风险是什么？」
观察：完全无法复述，或表示「医生说没有风险」、「您肯定给我做好」者。
无法理解并复述核心手术风险，判定【拦截】
C-10 不接受残余屈光误差的可能性 询问：「若术后仍有轻度近视、远视或散光，需配薄镜辅助，您能接受吗？」
观察：明确拒绝任何残余屈光不正，或认为花了全自费就「保证不需要戴镜」者。
拒绝接受任何残余屈光可能性，判定【预警/拦截】
第三域   心理状态与沟通支持
编号评估项目询问 / 观察要点判定标准评估结果
C-11 近期心理健康与支持需要 询问：「最近的睡眠、心情和身体状态，会影响您理解信息或做决定吗？有需要医生知道的治疗或用药吗？」
只记录患者自述及支持需要；不要凭用药或情绪表现自行诊断。
若当前难以理解信息或作自主决定，暂停方案确认并请医生评估；用药史本身不是自动拦截条件。
C-12 对细节及结果的要求 询问：「若术后总体改善，但某些场景未达到最理想效果，您最在意哪一点？」
观察：关注点是否具体、是否需要更清楚的解释；不根据提问次数判断人格。
若仍要求保证结果且无法理解局限，交医生进一步沟通；不作人格诊断。
C-13 对视觉波动的极度敏感史 询问：「配镜时是否因轻微度数偏差而多次退换？既往做过屈光手术且因轻微不适强烈不满者？」
观察：主诉对任何视觉变化极度敏感，适应期异常漫长者。
记录既往具体经历，交医生结合眼部检查评估；不能仅凭病史直接排除。
C-14 术前过度紧张 / 极度恐惧 观察：就诊时手抖、大汗、无法配合基础检查；
主诉「非常害怕手术」但仍被劝来就诊，本人情绪极度不稳者。
无法配合术前检查或极度恐惧，判定【预警】
第四域   社会心理与外部压力
编号评估项目询问 / 观察要点判定标准评估结果
C-15 外部强迫型就诊 询问：「是您主动想做这个手术，还是有人劝您来的？」
观察：被配偶、子女或单位要求手术，本人态度被动，言语中表现出抵触者。
本人无真实意愿，属被动就医，判定【拦截】
C-16 经济压力型勉强升级 观察：确认全自费价格后明显犹豫，多次询问能否分期；表示「借钱来做」或「家里人说太贵了」者。
询问：「本次手术费用是否在您舒适的经济范围内？」
明显经济压力且有后悔风险，判定【预警】
C-17 对医疗团队的不信任 观察：反复质疑医生资质、设备品牌、医院动机；本院有投诉或纠纷记录。
询问：「您是否信任我们的手术团队？」
逐项回应并核实疑虑；若关键问题未澄清，暂停方案确认。质疑或投诉史本身不是排除条件。
第五域   术后依从性与随访意愿
编号评估项目询问 / 观察要点判定标准评估结果
C-18 不能保证关键节点复诊 询问：「术后第1天、1周、1月须复诊，您能按时来吗？居住地距医院多远？」
观察：长期外地、无人陪同、明确表示「不方便复诊」者。
无法保证关键节点复诊，判定【预警】
C-19 用药依从性存疑 询问：「若术后需要按医嘱滴眼药，您自己操作方便吗？需要家人帮忙吗？」
观察：手部操作、药瓶说明阅读、记忆及家庭支持；用药时间以医生医嘱为准。
依从性明显不足，判定【预警】
C-20 对术后视觉适应期缺乏心理准备 询问：「如果术后视觉一开始与预想不同，您希望医院怎样帮助您？出现什么情况会立即联系我们？」
观察：是否了解视觉变化存在个体差异；异常症状先请医生检查，不承诺固定适应期限。
完全拒绝接受视觉适应期，判定【预警/拦截】

20项提问与观察指引

先开放提问，再解释选择和局限，最后请患者用自己的话复述。记录患者原话、已解释内容及待医生核实事项；观察仅记录具体事实，不据此诊断人格或心理疾病。本指引供宣教护士、咨询师初评及主诊医生复核使用。

C-01 手术目标

提问：“术后，您最希望哪三件日常事情变得容易？您预计能改善到什么程度？”

观察：是否期待恢复年轻时的全部视觉能力；解释后能否说出最看重的改善目标。

C-02 光晕、眩光接受度

提问：“您晚上开车或看灯光多吗？如果术后看灯时出现光圈、星芒，最担心影响什么？”

观察：夜间驾驶频率和安全要求；能否理解不同晶体的光学取舍。

C-03 戴镜预期

提问：“看小字或长时间阅读时仍可能需要眼镜，哪些场景您可以接受戴镜？”

观察：是否把少戴镜理解为任何时候绝不戴镜；说明后想法是否变化。

C-04 飞秒激光预期（仅拟选FLACS者）

提问：“您选择飞秒激光辅助手术，最看重什么？您认为它能保证什么结果？”

观察：是否认为设备能保证零风险、零误差或一定获得更好的术后视力。

C-05 职业视觉要求

提问：“您的工作需要夜间驾驶、辨色、精细近距离操作，或通过特定视力体检吗？有书面标准吗？”

观察：取得实际要求，交医生核对；不凭口头印象保证通过体检。

C-06 自费方案理解

提问：“有哪些可选方案？每种方案哪些费用可能由医保支付，哪些需要自己支付？您理解的费用差别是什么？”

观察：能否区分临床选择与支付安排；是否拿到本院适用的书面明细，不能预设所有地区均需放弃医保。

C-07 晶体特点与局限

提问：“请用自己的话说说，医生建议的晶体主要希望改善哪些距离的视觉？有什么局限？”

观察：是否把产品名称当成效果保证；能否复述适用条件和取舍。

C-08 FLACS及耗材费用（仅拟选FLACS者）

提问：“飞秒激光辅助部分及相关耗材怎样收费？您理解它们包含在哪张费用单里吗？”

观察：收费项目、眼别、次数和自费金额是否清楚；犹豫时留出提问和考虑时间。

C-09 手术风险理解

提问：“医生讲过的风险里，您印象最深的是哪些？术后若突然疼痛或视力下降，怎样联系医院？”

观察：能否复述与本人相关的主要风险及紧急联系方法；必要时重新用通俗语言解释。

C-10 残余度数预期

提问：“如果术后仍有一点近视、远视或散光，某些时候需要眼镜或进一步评估，您怎么看？”

观察：是否把目标屈光度误解为结果保证；医生是否说明个体差异。

C-11 近期心理健康与支持需要

提问：“最近的睡眠、心情和身体状态会影响您理解信息或做决定吗？有需要医生知道的治疗或用药吗？”

观察：只记录患者自述和支持需要；用药或既往诊断本身不能自动判定不适合，必要时由医生评估。

C-12 对细节及结果的要求

提问：“如果术后总体比现在好，但有一两个场景未达到最理想效果，您最在意哪一点？”

观察：关注点是否具体、能否讨论；反复提问可能表示解释不足，不能据此判断人格类型。

C-13 既往视觉适应经历

提问：“以前换眼镜、戴隐形眼镜或接受眼部治疗时，有没有难以适应的视觉变化？当时是什么情况？”

观察：记录具体症状、持续时间、原因与解决过程，交医生结合眼部检查判断。

C-14 手术恐惧与配合

提问：“手术中您最害怕什么？我们怎样说明或安排，会让您更安心？”

观察：能否完成必要检查，是否需要家属陪同或额外解释；明显不适时请医生评估。

C-15 本人意愿

提问：“这次手术和晶体选择，您自己希望怎么做？如果家人意见不同，您最想先弄清什么？”

观察：尽量让患者本人表达，确认是否被催促或由他人代替决定。

C-16 费用带来的压力

提问：“看过完整费用和其他合理方案后，您希望现在决定，还是带回去和家人商量？”

观察：是否知道可选方案、是否需要更多时间；不要询问无关收入细节或施压升级。

C-17 对医疗团队的疑虑

提问：“关于医院、医生、手术或费用，您还有哪些不放心？希望我们提供什么信息？”

观察：逐项核实疑虑和沟通是否一致；提出质疑或曾投诉不应自动视为不适合。

C-18 复诊安排

提问：“术后医生安排复诊时，您来院方便吗？若人在外地，怎样联系到您并安排检查？”

观察：交通、陪同、联系方式及可执行的复诊计划；具体时间以医嘱为准。

C-19 用药支持

提问：“如果术后需要按医嘱滴眼药，您自己操作方便吗？需要家人帮助吗？”

观察：手部活动、阅读药瓶说明、记忆及家庭支持；疗程以实际医嘱为准。

C-20 术后适应与求助

提问：“若术后一开始觉得与预想不同，您希望医院怎样帮助您？出现什么情况会立即联系我们？”

观察：能否区分需及时就医的异常与需复查、解释的适应问题；不承诺固定适应期限。

交接记录：患者原话、已解释内容、患者复述、待医生核实事项。重大误解、本人意愿不清或职业要求未核实时，暂停最终方案确认。量表不替代眼部检查、临床适应证评估和正式知情同意。
